# Módulo 1 — Fundamentos

## Objetivo

Usar objetos, vetores, funções e `data.frame` para responder perguntas simples com dados estruturados.

## Material

Execute primeiro o script [`exercicios/01-objetos-vetores-dataframes.R`](exercicios/01-objetos-vetores-dataframes.R). Ele usa apenas funções da instalação-base do R, sem pacotes adicionais.

## Como estudar

1. Leia um bloco de comentários.
2. Execute o código abaixo dele.
3. Altere valores e observe o efeito.
4. Resolva as tarefas marcadas com `# EXERCÍCIO` em um novo script.
5. Compare seu resultado com o que a pergunta pede, e não apenas com a ausência de erros.

## Ao terminar, você deve conseguir

- distinguir número, texto e valores lógicos;
- criar e indexar vetores;
- usar funções básicas como `mean()`, `sum()` e `length()`;
- criar um `data.frame`;
- selecionar linhas e colunas por condição.

Depois, avance para o script de manipulação de dados da Aula 2.

# Módulo 0 — Onde tudo começa

## Objetivo

Preparar o ambiente e compreender a lógica básica de trabalhar com R: escrever instruções em scripts, executá-las no console, observar os objetos criados e salvar um projeto reproduzível.

## Antes de começar

Instale **R** antes do RStudio. R é a linguagem que executa os comandos; RStudio é a interface que ajuda a escrever, organizar e rodar esses comandos.

- [Download do R](https://cran.r-project.org/)
- [Download do RStudio Desktop](https://posit.co/download/rstudio-desktop/)
- Material detalhado da aula: [`../Aula-0-Onde_tudo_comeca.Rmd`](../Aula-0-Onde_tudo_comeca.Rmd)

## Rotina de trabalho

1. Abra o arquivo `Curso-de-R.Rproj` no RStudio.
2. Crie ou abra um script `.R` para cada atividade.
3. Execute trechos pequenos com `Ctrl + Enter` (Windows/Linux) ou `Cmd + Enter` (macOS).
4. Leia toda mensagem do console: erros indicam o que não foi entendido pelo R; *warnings* indicam algo que merece atenção.
5. Salve o script. Não dependa do histórico do console para reproduzir uma análise.

## Atalhos úteis

| Ação | Windows/Linux | macOS |
|---|---|---|
| Executar linha/seleção | `Ctrl + Enter` | `Cmd + Enter` |
| Inserir `<-` | `Alt + -` | `Option + -` |
| Inserir pipe `|>` | `Ctrl + Shift + M` | `Cmd + Shift + M` |
| Limpar console | `Ctrl + L` | `Cmd + L` |

## Critério de conclusão

Você concluiu este módulo quando consegue abrir o projeto, criar um script, executar `2 + 2`, salvar um objeto com `<-` e reencontrar esse objeto no painel *Environment*.
